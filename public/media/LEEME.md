# Archivos que debes colocar aquí

La web ya reserva el espacio para cada uno. Solo copia el archivo con **este nombre exacto** y aparecerá solo (sin tocar código). Mientras no exista, se ve un marcador con el ícono de play (videos) o con la inicial (fotos).

## Videos (MP4, H.264, sin audio o silenciado)

| Archivo | Dónde se ve |
| --- | --- |
| `videos/preview/fuente.mp4` | Preview: Fuente de audio |
| `videos/preview/espectros.mp4` | Preview: Espectros y gráficas |
| `videos/preview/tematicas.mp4` | Preview: Temáticas |
| `videos/preview/paletas.mp4` | Preview: Paletas |
| `videos/preview/modos.mp4` | Preview: Modo claro y oscuro |
| `videos/preview/sensibilidad.mp4` | Preview: Sensibilidad y movimiento |
| `videos/preview/franja.mp4` | Preview: Franja y apps |

Recomendado: 1920×1080, menos de 6 MB cada uno, bucle corto de 6 a 15 segundos.
